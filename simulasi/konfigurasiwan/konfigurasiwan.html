01 • PENGANTAR ROUTING

Bagaimana Data Menemukan Jalan?

Bayangkan sebuah komputer di kantor pusat ingin mengirim data ke komputer di kantor cabang. Kedua komputer berada pada jaringan yang berbeda. Router harus menentukan ke mana paket data diteruskan.

Pengertian Routing

Routing adalah proses menentukan jalur dan meneruskan paket data dari satu jaringan ke jaringan lain melalui perangkat router berdasarkan informasi routing.

Analogi: Routing seperti seorang pengemudi yang mencari jalan menuju kota tujuan. Router adalah petunjuk arah, network destination adalah kota tujuan, sedangkan next hop adalah persimpangan atau router berikutnya yang harus dilewati.

Fungsi routing

📦
Meneruskan paketMengirim paket ke router atau antarmuka berikutnya.
🌐

⚖️
Mengelola ruteMenyimpan dan memilih informasi jalur.
02 • JENIS ROUTING

Static Routing vs Dynamic Routing

Pilih salah satu kartu untuk melihat cara kerja dan perbedaannya.

Static Routing

Administrator memasukkan rute secara manual ke router. Rute tidak otomatis berubah hanya karena kondisi jaringan berubah. Administrator perlu memperbarui konfigurasi jika jalur berubah.

Kelebihan: sederhana dan mudah dikontrol pada jaringan kecil.

Kekurangan: konfigurasi dan pemeliharaan bertambah ketika jaringan semakin besar.

Analogi: Static routing seperti kita menulis sendiri petunjuk perjalanan. Dynamic routing seperti menggunakan aplikasi navigasi yang mempelajari rute dari informasi jaringan dan memperbarui jalur sesuai kondisi.

Contoh protokol routing dinamis: OSPF, RIP, dan BGP. Masing-masing memiliki cara kerja dan skala penggunaan berbeda.

🎯 Network Destination

Network destination adalah alamat jaringan tujuan yang dicari oleh router. Contohnya 192.168.2.0/24 berarti jaringan dengan prefix /24 tersebut.

Analogi: Routing table seperti buku alamat dan peta perjalanan. Router membaca alamat tujuan, mencari rute yang sesuai, lalu meneruskan paket ke jalur berikutnya.
04 • DEFAULT ROUTE

Memahami Default Route

Bagaimana jika router menerima paket menuju jaringan yang belum tercantum secara spesifik dalam routing table?

Default Route: 0.0.0.0/0

Default route digunakan sebagai rute pilihan ketika tidak ditemukan rute yang lebih spesifik untuk tujuan paket. Pada IPv4, default route ditulis sebagai 0.0.0.0/0.

Biasanya digunakan untuk meneruskan trafik menuju jaringan luar atau internet melalui gateway ISP.

Analogi: Ketika kita tidak mengetahui alamat sebuah tempat, kita bertanya kepada petugas informasi. Petugas tersebut memberi petunjuk umum. Default route berperan seperti petunjuk umum tersebut.

06 • PRAKTIK STATIC ROUTING

Konfigurasi Routing Sederhana

Pilih router untuk melihat contoh perintah konfigurasi static route menggunakan MikroTik RouterOS v7.

Router 1

R1 memiliki jaringan lokal 192.168.1.0/24 dan terhubung ke R2 melalui 10.0.12.0/30. R1 perlu mengetahui jalur menuju LAN 2 dan LAN 3.

Perintah konfigurasi

/ip route add dst-address=192.168.2.0/24 gateway=10.0.12.2 /ip route add dst-address=192.168.3.0/24 gateway=10.0.12.2
Analogi: Kita sedang memberi tahu petugas kantor pos: "Jika ada paket untuk kota B atau C, kirim melalui kantor pos berikutnya."

Aktifkan jalur routing simulasi

07 • UJI KONEKTIVITAS

Apakah Jaringan Sudah Terhubung?

Setelah routing dikonfigurasi, teknisi perlu menguji komunikasi antarjaringan. Kita gunakan simulasi perintah ping.

ping 192.168.3.10

Siap melakukan pengujian

Pilih komputer sumber dan tujuan, lalu jalankan ping.

Ping menggunakan ICMP untuk menguji keterjangkauan alamat IP. Keberhasilan ping tidak selalu menjamin seluruh layanan aplikasi berjalan normal; firewall dapat memblokir ICMP.
